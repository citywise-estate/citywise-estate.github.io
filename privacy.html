プライバシーポリシー（Citywise Mail Intake）

Citywise Mail Intake（以下「本ツール」）は、シティワイズエステート合同会社（以下「当社」）が自社の業務管理のためだけに使用する内部ツールです。

1. 取得する情報

本ツールは、当社自身のGoogleアカウントにおいて、Gmailのメール（本文・添付ファイル）と、当社が作成したGoogleスプレッドシート・Googleドライブのファイルにアクセスします。当社以外の利用者の情報は取得しません。

2. 利用目的

取得した情報は、不動産関連のメールの整理・記録、および証憑の管理など、当社内部の業務管理のためだけに利用します。

3. 第三者への提供

取得した情報を第三者に販売・提供することはありません。広告の目的に利用することもありません。

4. 保管

情報は当社のGoogleアカウント内および当社の管理する端末内に保管し、業務上不要になったものは当社の規程に従って管理します。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによるGoogle APIから受け取った情報の利用および他のアプリへの転送は、限定的使用の要件を含む Google API Services User Data Policy に準拠します。

6. お問い合わせ

本ツールに関するお問い合わせは、Googleの同意画面に表示されるサポートメールアドレスまでご連絡ください。
